ABOUT THE PROJECT

About NMC Complaint Register

NMC Complaint Register is a student-developed web project created to demonstrate how a website can provide an interface for recording civic complaints and checking complaint information.

The project focuses on a simple user interface, clear navigation, complaint forms and a dedicated page for status tracking.

Academic project only. This website is not an official Nagpur Municipal Corporation portal. Complaints submitted here are not automatically sent to the municipal corporation.
